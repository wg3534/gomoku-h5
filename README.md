# 五子棋 · 微信好友联机对战（H5 网页版）

一个**单文件前端 + 一个 Node 服务器**的五子棋，朋友在微信里点开链接就能和你实时对战，**无需下载、不用注册小程序**。

- 创建房间 → 把链接/二维码发到微信 → 好友点开自动进房间
- 实时同步落子（WebSocket，延迟通常 <200ms）
- 悔棋协商（对方同意才生效）、表情/快捷语互动、认输、再来一局（交换黑白，败方先手）
- 落子音效、最后一手红点标记、获胜五子红线高亮
- 断线自动重连、房间 10 分钟无人自动回收

---

## 一、本地运行（先自己试玩）

```bash
cd gomoku-h5
npm install        # 安装 ws 依赖（已包含在 package.json）
npm start          # 默认 http://localhost:3000
```

浏览器开两个标签页，都访问 `http://localhost:3000`：
- 一个「创建房间」，复制房间号
- 另一个「加入房间」输入房间号
即可两人对下。想看成品 UI 直接访问 `http://localhost:3000/?demo=1` 是带结算覆盖层的样例棋盘。

> 手机和电脑同一 WiFi 时，手机用电脑内网 IP 访问（如 `http://192.168.x.x:3000`）也能联机。

## 二、一键部署到云端（微信好友点链接即玩）

> ✅ **我已完成的准备**：`render.yaml` 部署配置（免费套餐、自动 `npm install` + `npm start`、端口 10000、健康检查 `/`）已就绪；本地仓库已 `git init` 并提交干净（不含 `node_modules`）。本地冒烟测试通过（`/` 与 `/?demo=1` 均返回 200）。
>
> ⚠️ **唯一需要你动手的**：把代码推到**公开的 GitHub 仓库**，然后点下面的「Deploy to Render」按钮。这一步无法由我代点（需要你本人的云账号登录），其余全自动，约 2 分钟上线、全程免费。

### 第 1 步：推到 GitHub（公开仓库）

```bash
cd gomoku-h5
git remote add origin https://github.com/你的用户名/gomoku-h5.git
git branch -M main
git push -u origin main
```

### 第 2 步：一键部署（点按钮）

把下面链接里的仓库地址换成你自己的，打开后登录免费的 Render 账号，点 **Create Web Service** 即可：

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/你的用户名/gomoku-h5)

上线后得到 `https://gomoku-h5-xxxx.onrender.com`，发到微信即可玩。

> 免费版注意：长时间无访问会「休眠」，好友第一次打开可能要等 ~30 秒唤醒，之后就快了。`.onrender.com` 在微信里偶尔弹「已停止访问该网页」安全提示，点「继续访问」即可（非程序问题，属微信对未备案域名的通用提示）。

### 方式 B：其他免费/低价平台

- **Fly.io**：`fly launch` 按提示部署（免费额度有限）。
- **Railway / Koyeb / 国内的 宝塔+云服务器**：均可，只要能跑 `node server.js` 并提供公网 HTTPS 即可（WebSocket 用 `wss://`，HTTPS 站点自动支持）。
- 关键点：前端用 `wss://` 还是 `ws://` 由页面协议自动判断，**只要站点本身是 HTTPS**，联机就走加密通道，微信里也能正常用。

## 三、在微信里怎么和朋友玩

1. 部署拿到公网地址（如 `https://gomoku-h5-xxxx.onrender.com`）。
2. 手机微信里打开这个地址 → 点「创建房间」→ 页面会自动生成**分享链接 + 二维码**。
3. 点「复制」把链接发到微信群/好友，或直接把二维码截图发过去。
4. 好友在微信里点链接（或扫二维码）→ 自动进入同一房间，黑棋先手开下。

> 微信打开外部链接偶尔会先弹一次「已停止访问该网页」的安全提示，点「继续访问」即可（这是微信对未备案域名的通用提示，非程序问题）。若想彻底消除，可给域名做微信**业务域名**配置（需公众号），普通好友间娱乐通常不必。

## 四、技术要点

- **实时同步**：浏览器 `WebSocket` 直连服务器（与 HTTP 同端口），服务器 `broadcast` 房间内状态，前端只读 + 重绘。
- **防作弊 / 权限**：所有「写操作」（落子、悔棋、认输、重开）都在**服务端校验回合与落子合法性**，前端无法伪造。
- **断线重连**：连接断开后前端自动重连并 `join` 同一房间，回到自己原来的座位（按离线前颜色入座）。
- **房间内存存储**：单实例、内存态，重启即清空（免费套餐够用；如需持久化可换 Redis/数据库）。

### 文件结构
```
gomoku-h5/
├── server.js            # Node 服务：静态托管 + WebSocket 房间管理 + 五连判定
├── package.json         # 依赖 ws，npm start
├── render.yaml          # Render 一键部署配置（免费套餐）
├── public/
│   └── index.html       # 全部前端（首页 + 对战页 + canvas 棋盘 + 音效 + 分享），单文件自包含
└── README.md
```

### 可调项
- 棋盘大小：`server.js` 顶部 `const N = 15`（同时前端 `index.html` 里也有 `var N = 15`，保持一致）。
- 房间回收时间：`server.js` 的 `ROOM_TTL`（默认 10 分钟）。
- 免费套餐休眠：Render 免费版无法关闭休眠，仅影响首屏唤醒速度。
